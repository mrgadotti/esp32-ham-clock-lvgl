# Final code review: ESP32-HAM-CLOCK-LVGL (main @ 2defba6)

Scope: whole codebase (src/, lib/core/, tools/, web/config.html, platformio.ini, include/lv_conf.h), read-only.
Goals: correctness, code-size/duplication reduction, optimizations. Nothing was edited, committed or flashed.
All measurements below come from builds made in scratch copies (the worktree sources were not touched).

Recommended hybrid: `-Os` globally plus `-O2` only on the LVGL blend/draw hot files and TFT_eSPI (expected to give back about 10-15 KB).

### 2.2 Concurrency

Audit result: LVGL is touched only from the UI task (uiTask, indev read callback, flush callback; `touchCalRun` is reached through the `StartTouchCal` event, `handleResetTouch` only posts an event). Cross-task data goes through `g_store` (`Guarded`), `cfgGet`, the 4-slot `UiEvent` queue and `std::atomic` flags (events.cpp, rgb_led.cpp, mem_log.cpp, ui_manager.cpp). Lock order is consistent (`aprs_ingest::mu` then config `g_mutex`; `Guarded` callbacks never nest stores; `qrz s_mu` is a leaf). No lock is held across network I/O. Real violations: C-03 (QRZ uses `cfg()`), C-06 (NVS under the mutex), plus:

## 3. Notes backing the findings

- **First-fetch allocation (M-06).** Data points: boot largest 110 KB, post-WiFi 73.7 KB, idle after first fetch 34.8-51.2 KB. If `free` before/after the first TLS fetch is unchanged while `largest` drops, it is fragmentation by a pinned small block; if `free` drops by the same amount as `largest`, it is a retained allocation and the `heap_caps_dump` address list names the owner.
- **Why the LV_MEM crash class is believable.** `lv_obj_class_create_obj` and `lv_mem_core_builtin` use `LV_ASSERT_MALLOC`; the handler loops forever (lv_conf.h:337). With the task watchdog on CPU0 idle only, a spinning UI task on core 1 never reboots the chip.
- **Font trim (F-06).** The characters used by `i18n.h`/sources are U+00B0, U+00C1, C3, C7, C9, CD, D3, D5, DA, E0-E3, E7, F3, F5, plus U+00D7 and U+00EA. Weather/city text from OpenWeather can contain any Latin-1 letter, so only the punctuation block (U+00A0-U+00BF except the degree sign, U+00D7, U+00F7) is safe to drop.
- **-Os vs -O2.** Only project sources, LVGL, TFT_eSPI and ArduinoJson are recompiled; the IDF/Arduino core is prebuilt at -Os already.
- **Tests.** `pio test -e native` passes 131 cases. Suites exist for every parser and state machine in lib/core; nothing in `src/` has a test.
- **Not verified (needs hardware):** actual fps with -Os, rendering with ARGB8888 off, which transition peaks LV_MEM, first-fetch heap layout, HamAlert stall duration on the user's network.
